# Security Policy

## Reporting Security Vulnerabilities

We take the security and privacy of JaMeet users seriously. If you discover a security vulnerability or potential threat in JaMeet, please report it responsibly.

### How to Report

Please **do not** report security vulnerabilities via public GitHub issues or discussions.

Instead, please send an email to:
**ofir40050@gmail.com**

Please include:
- A description of the issue and potential impact.
- Step-by-step instructions to reproduce the vulnerability (proof-of-concept script, network requests, or configuration).
- Affected components (Desktop client, Signaling Server, WebRTC, Native Driver).

### Response Timeline
- We will acknowledge receipt of your report within 48 hours.
- We will investigate and provide regular updates until a security patch is deployed.
- We appreciate your efforts to keep JaMeet secure for our users.
