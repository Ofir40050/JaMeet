# Project Guidelines & Rules

## Implementation Plan Approval
- Whenever creating or updating an Implementation Plan (`implementation_plan.md`), the agent must **always pause and wait for explicit approval from the user** before proceeding with any code edits, modifications, or execution.
- Never proceed automatically without explicit user confirmation.

## Automatic GitHub Push
- At the conclusion of every task or action, the agent must **always commit and push all changes to GitHub** (`git push origin main`).
